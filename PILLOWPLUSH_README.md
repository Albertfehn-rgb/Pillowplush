# PillowPlush Konfigurator V1

Abgeleitet aus PicturePlush V18.

- Größen 20 × 20 cm bis 100 × 100 cm in 1-cm-Schritten
- keine Aufhängungen
- Verschlüsse: Reißverschluss, Knöpfe, Hotelverschluss
- automatische 3D-Vorschau und 2D-Umschaltung bleiben erhalten
- gespiegelte Rückseite und geschlossene Außenkontur bleiben erhalten
- Randabstand 0–15 (intern 5–20 %) bleibt erhalten
- Polsterdicke wurde für Kissen auf größere, größenabhängige Werte angepasst
